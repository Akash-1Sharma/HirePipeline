# HirePipeline

**A personal opportunity management platform.**

HirePipeline helps users capture, organize, track, and manage job opportunities shared from LinkedIn and other supported applications.

## Project Vision

Build a cross-platform opportunity management system that provides a consistent experience across Web, Android, and iOS.

## Platforms

- Web application
- Android application
- iOS application
- Shared backend API

## Technology Stack

| Component | Technology |
|---|---|
| Backend | Python, FastAPI |
| Web | Next.js, TypeScript |
| Mobile | React Native, TypeScript |
| Database | PostgreSQL |
| ORM | SQLAlchemy 2.0 |
| Migrations | Alembic |
| API | REST, versioned `/api/v1/` |

## Core Capabilities

- Capture opportunities through supported sharing mechanisms.
- Extract and organize opportunity information.
- Manage application status and deadlines.
- Create reminders and notifications.
- Search, filter, and organize opportunities.
- Synchronize data across supported platforms.
- Export and import opportunity data.

## Engineering Principles

- Security and privacy by design.
- Maintainable and modular architecture.
- Efficient database queries and indexing.
- Automated testing and code quality.
- Consistent API contracts across platforms.
- Accessible and responsive user experiences.
